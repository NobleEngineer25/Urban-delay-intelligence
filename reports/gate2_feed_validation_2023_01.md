## Method

- **Geocoding:** city-supplied lat/lon is kept when it falls inside the Chicago bounding box (lat (41.6, 42.1), lon (-88.0, -87.5)). Records without it are matched offline to the nearest known house number on the same street (within 200 numbers, about 400 m), using every raw 311 and permit file as the address reference.
- **H3:** every geocoded record is tagged with its resolution-8 cell (output: `data/processed/disruptions_h3_YYYY_MM.parquet`).
- **Community areas:** 311 records carry one. Permits borrow the most common 311 community area in the same H3 cell, so permit coverage is approximate.
- **Temporal:** 311 counts requests created per day; permits count segments active on each day.
